# Agent rules for this project

Work is one markdown file per task under `work/tasks/<week>/`. The conventions
in [work/README.md](./work/README.md) are binding: global monotonic numbering,
the `x_` prefix for a finished task, `git mv` for every move, and personal-data
redaction before `git add`. Obtain the next free number with `work next-id`.

Judgement calls follow [work/POLICY.md](./work/POLICY.md): what may be decided
alone, what runs on a default, what waits for a person.

Refer to tasks only by their id (`T-26-001`); never store a path or a link to a
task file.

Everything below is project-specific.
